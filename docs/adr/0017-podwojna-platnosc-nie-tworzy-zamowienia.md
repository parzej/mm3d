# Podwójna płatność nie tworzy drugiego zamówienia

Dla jednego wariantu tej samej sprawy powstaje tylko jedno zamówienie. Jeżeli wskutek ponowienia, równoległych prób albo błędu klient skutecznie zapłaci dwa razy za ten sam wariant, druga wpłata nie zwiększa liczby zamówionych egzemplarzy i nie tworzy kolejnego zamówienia. MM3D zwraca nadmiarową wpłatę klientowi.

Drugie zamówienie może powstać wyłącznie na podstawie nowego, wyraźnego zlecenia klienta. Sposób rozpoznawania dwóch transakcji, blokowania kolejnych płatności, wykonania zwrotu i zachowania historii rozstrzyga Parzej.

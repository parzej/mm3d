# Wstrzymanie sprawy po braku odpowiedzi klienta

Gdy przygotowanie wyceny wymaga informacji klienta, MM3D wysyła jedno przypomnienie po 5 dniach roboczych bez odpowiedzi. Po kolejnych 5 dniach roboczych sprawa zostaje wstrzymana, a MM3D nie wykonuje przy niej dalszych działań. Sprawa nie jest usuwana ani traktowana jako zamówienie; klient może ją później wznowić przez odpowiedź w tym samym wątku z zachowaniem numeru sprawy.

Po wznowieniu ponownie zaczyna biec dwudniowy czas reakcji MM3D, ale wcześniejsze rozmowy nie gwarantują przyszłej ceny, dostępności ani terminu. Wybrano wstrzymanie zamiast trwałego zamknięcia, aby klient nie musiał powtarzać całego zgłoszenia, a jednocześnie MM3D nie utrzymywało bezterminowo aktywnego zadania oczekującego na klienta.

# Korekta danych nie jest zmianą wyceny

W końcowym podsumowaniu przed Paynow klient może samodzielnie poprawić imię i nazwisko odbiorcy, telefon, e-mail, Paczkomat lub adres oraz dane nabywcy i faktury, jeżeli poprawka nie zmienia zakresu, ceny ani terminu. Taka korekta nie tworzy nowej wersji wyceny.

Zmiana wariantu, liczby sztuk, wymiaru, usług dodatkowych lub sposobu dostawy wpływającego na koszt wymaga powrotu do MM3D. MM3D przygotowuje wtedy nową kompletną wersję wyceny i nową możliwość płatności, a klient ponownie sprawdza podsumowanie oraz akceptuje regulamin. Wybrano tę granicę, aby literówka nie uruchamiała ponownej wyceny, a klient nie mógł jednostronnie zmienić opłacanego świadczenia.

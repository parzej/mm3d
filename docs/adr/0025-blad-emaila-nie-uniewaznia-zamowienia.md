# Niedostarczony e-mail nie unieważnia zamówienia

Zamówienie powstaje w chwili potwierdzenia pełnej płatności przez Paynow, niezależnie od tego, czy automatyczny e-mail dotrze do klienta. Błąd dostarczenia nie unieważnia zamówienia i nie przesuwa terminu realizacji. Prywatna strona nadal pokazuje trwałe podsumowanie opłaconego zamówienia.

System ponawia wysłanie wiadomości, a po trwałym błędzie informuje MM3D o potrzebie ręcznej obsługi. Ponowienie nie może utworzyć kolejnego zamówienia ani uruchomić ponownie obsługi płatności. Liczbę prób, rozpoznawanie błędów trwałych i alerty rozstrzyga Parzej.

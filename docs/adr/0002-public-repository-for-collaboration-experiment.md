# Publiczne repozytorium dla eksperymentu współpracy

Repozytorium MM3D jest publiczne od pierwszego pushu, ponieważ pierwsza faza ma bez dodatkowych kosztów sprawdzić, czy niezależne lokalne sesje parzeja i Górasa potrafią bezpiecznie kumulować wspólny słownik domenowy oraz decyzje techniczne. Zespół akceptuje jawność kodu, ADR-ów, słownika i niestrategicznych treści pierwszej wersji; żadne sekrety, dane klientów ani prywatne załączniki nie mogą trafić do repozytorium lub jego historii. Decyzję o płatnych usługach można podjąć dopiero po ocenie powodzenia eksperymentu.

# Utracony prywatny link jest zastępowany nowym

Klient może odzyskać dostęp do strony wyceny albo podsumowania opłaconego zamówienia bez zakładania konta. Wysyła prośbę z adresu e-mail przypisanego do sprawy, a po jej weryfikacji MM3D wydaje nowy prywatny link. Poprzedni link zostaje unieważniony.

Sposób weryfikacji, automatyzację wydania linku, ograniczenie prób i procedurę na wypadek utraty dostępu do pierwotnej skrzynki rozstrzyga Parzej.

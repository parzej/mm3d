# Dwudniowy czas reakcji MM3D podczas uzgodnień

MM3D odpowiada maksymalnie w ciągu dwóch dni roboczych od pierwszego zapytania klienta oraz od każdej późniejszej wiadomości, która przekazuje informacje potrzebne do następnego działania po stronie MM3D. Odpowiedzią może być kompletna wycena, kolejne konieczne pytanie albo odmowa realizacji. Po wysłaniu odpowiedzi termin przestaje biec i rozpoczyna się ponownie, gdy klient dostarczy wymagane uzupełnienie.

Termin opisuje czas reakcji MM3D, a nie gwarantowany czas zakończenia całego uzgadniania ani wykonania wydruku. Wybrano tę regułę, aby klient wiedział, kiedy otrzyma następny konkretny krok, również gdy wycena wymaga kilku wymian e-mailowych.

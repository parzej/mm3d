# Aktywna wycena może być wycofana tylko wyjątkowo

Wycena co do zasady obowiązuje przez pełne siedem dni kalendarzowych. Przed potwierdzeniem płatności MM3D może ją wcześniej wycofać wyłącznie z wyjątkowej przyczyny, takiej jak oczywisty błąd ceny, niewykonalność projektu, brak materiału albo przeszkoda prawna. Klient jest o tym niezwłocznie informowany, wszystkie możliwości płatności zostają zablokowane, a wersja pozostaje widoczna tylko do odczytu.

Jeżeli realizacja pozostaje możliwa na zmienionych warunkach, MM3D przedstawia poprawioną kompletną wersję wyceny. Zasada nie pozwala wycofać zamówienia, które już powstało przez potwierdzoną płatność. Techniczną obsługę płatności rozpoczętej tuż przed wycofaniem oraz atomowe blokowanie wariantów rozstrzyga Parzej, a dopuszczalność i treść klauzuli weryfikuje prawnik.

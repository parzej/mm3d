# Statyczny SvelteKit z backendem PHP na LH.pl

Pierwsza wersja MM3D używa Svelte 5 ze składnią legacy Svelte 4, SvelteKit, TypeScript i `adapter-static`, a GitHub Actions buduje statyczny frontend i wdraża go na istniejący hosting współdzielony LH.pl. Instalowalna PWA udostępnia wcześniej zapisane treści offline, ale nie kolejkuje zapytań ani plików; formularz działa online przez niewielki backend PHP 8, który zapisuje minimalne metadane w MySQL, przechowuje załączniki poza publicznym katalogiem przez 30 dni i powiadamia istniejący adres e-mail Górasa. Wybrano ten podział zamiast WordPressa, CMS-a lub serwera Node.js, aby zachować komponentowy frontend i automatyczne wdrożenia bez kupowania nowej infrastruktury ani uzależniania strony od środowiska niewspieranego przez posiadany hosting.

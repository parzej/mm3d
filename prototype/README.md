# Prototyp strony MM3D

Samodzielna makieta HTML przygotowana 12 sierpnia 2026. Nie jest wdrożeniem produkcyjnym i nie wysyła danych ani plików.

## Podgląd

Otwórz `index.html` w przeglądarce albo uruchom prosty serwer statyczny w tym katalogu.

Makieta obejmuje:

- stronę główną;
- formularz „Wyślij plik do wyceny”;
- formularz „Nie masz modelu? Opisz swój pomysł”;
- responsywny układ od małego telefonu do dużego ekranu;
- robocze teksty i stany informacyjne.

Formularze przechwytują wysłanie lokalnie i pokazują informację o prototypie. Nie mają backendu, Paynow, InPost ani trwałego zapisu.
